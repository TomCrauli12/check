# Check

Простой PHP-сайт для работы с задачами.

Возможности:

- создание задачи;
- изменение задачи;
- удаление задачи;
- просмотр списка задач;
- PHPUnit-тесты для создания, изменения и удаления.

Данные находятся в `database/tasks.json`, поэтому база данных не требуется.

## Установка

```powershell
composer install
```

## Запуск сайта

```powershell
php -S localhost:8000 -t public
```

После запуска откройте `http://localhost:8000`.

## Запуск тестов

```powershell
composer test
```
